# LOTE RIA — Proyecto Integrador de Comercio Electrónico

Plataforma web B2C en paleta **Negro, Rojo y Blanco** para la comercialización de **vehículos seminuevos y usados certificados** en México, con identificación explícita de **unidades nuevas (0 km)**.

## Instalación rápida en Figma Make / Next.js
1. Abre `src/app/(frontend)/LoteRiaApp.tsx` en Figma Make.
2. Borra su contenido, escribe `'use client';` en la primera línea y pega todo el código de `frontend/src/App.tsx`.
3. Guarda con `Ctrl + S` y recarga la vista previa.
