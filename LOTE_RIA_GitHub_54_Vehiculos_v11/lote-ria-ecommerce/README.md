# LOTE RIA — Proyecto Integrador de Comercio Electrónico

Plataforma web B2C en paleta **Negro, Rojo y Blanco** con **54 vehículos** (seminuevos certificados y unidades nuevas 0 km), autenticación realista con registro de cuentas, cumplimiento legal mexicano (**LFPC**, **LFPDPPP 2025**, **Código de Comercio**, **NOM-122-SCFI**), base de datos PostgreSQL en 3FN y backend Express.

## Credenciales de Prueba (Pestaña "Iniciar Sesión / Registro")

- **Cliente Comprador:** `cliente@loteria.mx` / `ClienteLote2026#`
