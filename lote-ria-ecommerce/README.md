# LOTE RIA — Plataforma de Comercio Electrónico Automotriz

Plataforma oficial B2C en paleta **Negro, Rojo y Blanco** con **54 vehículos** (seminuevos certificados y unidades nuevas 0 km), pasarela de pagos con tarjeta, autenticación segura con registro de cuentas, cumplimiento normativo en México (**LFPC**, **LFPDPPP 2025**, **Código de Comercio**, **NOM-122-SCFI**), base de datos PostgreSQL en 3FN y backend Express.

## Seguridad y Confidencialidad
- Las credenciales administrativas son confidenciales y se encuentran documentadas exclusivamente en el Manual de Usuario autorizado.
- El panel administrativo incluye sincronización de estado entre navegadores mediante enlace codificado (`?estado=...`).
