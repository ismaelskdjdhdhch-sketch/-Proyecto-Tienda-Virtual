# LOTE RIA — Plataforma de Comercio Electrónico Automotriz

Plataforma oficial B2C en paleta **Negro, Rojo y Blanco** con **54 vehículos** (seminuevos certificados y unidades nuevas 0 km), pasarela de pagos con tarjeta, autenticación segura con registro de cuentas, sincronización automática en la nube mediante **Supabase PostgreSQL**, cumplimiento normativo en México (**LFPC**, **LFPDPPP 2025**, **Código de Comercio**, **NOM-122-SCFI**), base de datos en 3FN y backend Express.
